Pengaturan Cloud Supabase (Netlify)

Agar berkas yang diunggah di domain .netlify.app tersimpan permanen di cloud dan bisa dibuka oleh seluruh teman kelas & dosen, hubungkan ke proyek Supabase gratis Anda:

Panduan Cepat (1 Menit):
  1. Buka supabase.com > Buat Project Baru (Gratis).
  2. Buka menu Storage > Klik New Bucket > Beri nama ti24a-files dan centang Public bucket.
  3. Buka menu SQL Editor > Salin & Jalankan skrip dari berkas supabase_setup.sql.
  4. Buka Project Settings > API > Salin Project URL dan anon/public key ke form di atas!
